## English description (draft)
SApay is a demonstration wallet experience created to explore a digital wallet interface in a test environment.

The demo allows users to:
- Create a demo wallet.
- View demo balances and activity.
- Simulate transfers between demo wallets within the test environment.

**Important:** This version is for demonstration and evaluation only. It does not move real money, connect to banks or payment networks, or represent a licensed financial institution or live financial service.

## Review notes (draft)
