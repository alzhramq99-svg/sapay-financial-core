# SApay v0.1.0-beta.1 — ملاحظات الإصدار

**التاريخ:** 6 نوفمبر 2026  
**القناة:** Private Beta  
**النطاق:** Demo only؛ لا أموال حقيقية ولا ربط بنكي فعلي ولا ترخيص مالي.

## ما يتضمنه الإصدار

- واجهة ويب عربية متجاوبة للاستخدام من الهاتف.
- إنشاء الحساب وتسجيل الدخول باستخدام رموز Bearer.
- محافظ تجريبية SDG وUSD.
- شحن تجريبي وتحويل تجريبي داخل بيئة الاختبار فقط.
- تخزين PostgreSQL ودفتر أستاذ مزدوج القيد.
- عزل المحافظ بحسب المستخدم وسجل تدقيق.
- حدود معدل لمسارات المصادقة وواجهات API.
- مؤشرات صحة API وقاعدة البيانات.

## نتائج التحقق المسجلة

- اختبارات الوحدات: 5 مجموعات / 32 اختبارًا ناجحًا.
- اختبارات تكامل PostgreSQL: 11 اختبارًا ناجحًا في التشغيل السابق.
- بناء NestJS: ناجح.
- بناء صورة Docker للإصدار: ناجح محليًا باسم `sapay-core15-api:v0.1.0-beta.1`.
- CI على commit `d838d0f`: ناجح.
- فحص صحة API وقاعدة البيانات: ناجح.
- تحقق عملي من حسابين منفصلين ومحفظتي SDG بمالكين مختلفين.
- نسخة PostgreSQL الاحتياطية `sapay_demo_prebeta_2026-11-06.dump` اجتازت التحقق من SHA-256.

## قيود وتحذيرات

- هذا إصدار قبول خاص، وليس إصدار إنتاج عام.
- رابط Codespaces خاص ومؤقت، وليس استضافة دائمة.
- لا تُدخل أموالًا أو بيانات مالية أو شخصية حقيقية.
- محدد المعدل داخل الذاكرة؛ يلزم تخزين مركزي عند تعدد النسخ.
- يلزم استكمال مراجعة أمنية مستقلة وخطة إبطال الجلسات قبل فتحه لمستخدمين خارجيين على نطاق أوسع.
- أمر `npm run lint` غير قابل للتنفيذ حاليًا لأن ESLint غير مثبت ضمن تبعيات المشروع؛ لم يتم اعتبار lint ناجحًا.

## الاستعادة

قبل أي ترقية لقاعدة البيانات، احتفظ بنسخة احتياطية جديدة وتحقق من بصمتها. لا تحذف الـ volumes الحالية.
